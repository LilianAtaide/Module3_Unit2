# Tip Calculator

A web application that will allow the user to:
1. Type in a bill amount - a positive floatin point number (not infinity), it will be provided as a string that has up to a 2 decimal digits
2. Type in a tip percentage - undecide wether we take this as a whole number or a decimal, but it has to be positive
3. Click a button to calculate the tip - do we need a button at all? Maybe just have it change on input
4. See the tip amount
5. See the total including the tip

Error handling. If either of the inputs are invalid, fail gracefully with a proper error message
